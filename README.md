# Katakumba Print — Calculadora 3D

Site estático: HTML, CSS e JavaScript. Não precisa de backend, banco de dados, Vercel ou dependências externas.

## Publicar gratuitamente no GitHub Pages
1. Crie no GitHub um repositório público chamado `katakumba-calculadora`.
2. Clique em **Add file → Upload files** e envie `index.html` (este é o único arquivo necessário para o site funcionar).
3. Clique em **Commit changes**.
4. Entre em **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
7. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/katakumba-calculadora/`.

Os cálculos rodam no navegador. Os dados ficam salvos localmente no navegador/dispositivo; não sincronizam entre dispositivos. O botão Exportar gera CSV compatível com Excel. Taxas de marketplace são exemplos editáveis, não tarifas oficiais garantidas.
