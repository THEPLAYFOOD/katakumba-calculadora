# Katakumba Print — Calculadora de custos 3D

Calculadora estática em HTML, CSS e JavaScript, com identidade visual inspirada na marca Katakumba: fundo escuro, detalhes em vermelho e tipografia em tons de osso.

## Arquivos necessários
- `index.html` — site e calculadora.
- `katakumba-logo.png` — logo usada no cabeçalho.

## Publicar gratuitamente no GitHub Pages
1. Crie no GitHub um repositório público chamado `katakumba-calculadora`.
2. Envie **os dois arquivos** (`index.html` e `katakumba-logo.png`) para a raiz do repositório.
3. Clique em **Commit changes**.
4. Entre em **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
7. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/katakumba-calculadora/`.

## Recursos
- Cálculo de custos por lote e por peça.
- Simulação de taxas e lucros em marketplaces.
- Estimativa de retorno do investimento na impressora.
- Salvamento dos campos no navegador via `localStorage`.
- Exportação do resumo para CSV.
- Layout responsivo para desktop e celular.

Os cálculos rodam no navegador. Os dados ficam salvos localmente no navegador/dispositivo e não sincronizam entre dispositivos. As taxas de marketplace são valores iniciais editáveis, não tarifas oficiais garantidas.
